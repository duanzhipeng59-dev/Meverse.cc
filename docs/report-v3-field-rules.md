## 01 人生画像(7 字段)

### 旺衰定性

- **职责**:日主旺衰的定性结论与人格底色
- **输入数据**:anchors.strength、anchors.dayMaster、anchors.monthOrder、facts.wuXing
- **触发条件**:按旺衰档位(从强/身强/偏强/中和/偏弱/身弱/从弱)与得令得地得势明细差异化;从格必须点明弃命从势的逻辑
- **命理推导规则**:
  - 开头直接定性「锚点档位」,档位词必须与锚点完全一致,不得输出锚点之外的档位
  - 引用得令/得地/得势中最有辨识度的 1-2 条依据(具体干支)
  - 点名最强五行及其十神身份,描述其力量在人格上的表现
  - 从格(从强/从弱)需写明日主孤立无援或一气专旺的结构,顺势而为的生存策略
- **必引证据**:structure.strength
- **写作结构**:结论(档位+一句人格定性)→ 命理依据(1-2条干支级证据)→ 现实解读(行为模式)→ 无需提醒段
- **字数上限**:260 字
- **语气**:命理师断语,克制、直接、有判断力
- **禁止**:输出锚点之外的旺衰档位;中和盘写成身强或身弱;绝对化人格断言
- **依赖字段**:无
- **机器校验**:必须含「」结论词;必须引用具体干支

### 道法与喜忌

- **职责**:命局主线结构(道法标签)与喜忌总述
- **输入数据**:anchors.pattern、anchors.fuYong、anchors.tenGods、anchors.tiaoHou
- **触发条件**:道法标签由格局+前两大十神组合决定(如伤官生财/杀印相生/食神制杀/官印相生);扶抑与调候同向或冲突决定喜忌叙述的侧重
- **命理推导规则**:
  - 开头给出道法标签「XX」(4-6字,最多8字,单标签)
  - 解释该组合的天然优势与做事风格;若调候与扶抑冲突,须提示权衡而非只报喜用
  - 以人物定性句收出(你天生…/你不是…而是…式)
- **必引证据**:structure.pattern / structure.favorable / structure.tiaohou
- **写作结构**:道法标签 → 组合优势解释 → 喜忌的现实含义 → 人物定性收束
- **字数上限**:200 字
- **语气**:画像式,专业但落地
- **禁止**:把多个结构塞进一个道法标签;调候用神与扶抑喜用混为一谈
- **依赖字段**:旺衰定性
- **机器校验**:必须含「」结论词

### 喜神

- **职责**:最喜的两行五行(一行式清单)
- **输入数据**:anchors.fuYong.favorable、anchors.fuYong.mapping
- **触发条件**:喜用五行由旺衰档确定性给出(身强克泄耗/身弱生扶/从势顺势/中和补弱),只列清单不展开
- **命理推导规则**:
  - 严格按锚点列两行,每行=五行(十神,带来…短语)
  - 五行与十神身份必须与锚点 mapping 一致
- **必引证据**:structure.favorable
- **写作结构**:一行式:五行（十神，带来…）、五行（十神，带来…)
- **字数上限**:60 字
- **语气**:克制清单
- **禁止**:展开成段;列出锚点之外的五行
- **依赖字段**:旺衰定性
- **机器校验**:常规(禁词/字数/干支存在性)

### 忌神

- **职责**:最忌的两行五行(一行式清单)
- **输入数据**:anchors.fuYong.cautious、anchors.fuYong.mapping
- **触发条件**:忌神由旺衰档确定性给出;短语写带来的竞争/消耗/束缚
- **命理推导规则**:
  - 严格按锚点列两行,与喜神同一行式
  - 忌神短语须具体(何种消耗、何种束缚)
- **必引证据**:structure.cautious
- **写作结构**:一行式:五行（十神，带来…）、五行（十神，带来…)
- **字数上限**:60 字
- **语气**:克制清单
- **禁止**:展开成段;恐吓式表述
- **依赖字段**:旺衰定性
- **机器校验**:常规(禁词/字数/干支存在性)

### 闲神

- **职责**:中性五行的边界说明
- **输入数据**:anchors.idle、facts.wuXing
- **触发条件**:闲神=不在喜忌清单的五行;无闲神时明确写无并一句带过
- **命理推导规则**:
  - 列出闲神五行(十神),一两句说明中性作用与边界
  - 无闲神写「无」加一句说明
- **必引证据**:structure.cautious
- **写作结构**:五行（十神）起头 → 中性作用 → 边界一句
- **字数上限**:90 字
- **语气**:平实
- **禁止**:把闲神写成喜或忌
- **依赖字段**:喜神、忌神
- **机器校验**:常规(禁词/字数/干支存在性)

### 神煞底色

- **职责**:驿马/阳刃/桃花三项的底色解读
- **输入数据**:facts.shenSha
- **触发条件**:按每项有/无分化:有则写落点柱位与引动特征;无则解读这种无的人命意义
- **命理推导规则**:
  - 分驿马/阳刃/桃花三行,每行名称:有/无——解读
  - 有则引用落点地支与柱位(以年支/日支查得)
  - 无的解读用倾向性表述(如驿马无=轨迹相对安稳)
- **必引证据**:shensha.yima / shensha.yangren / shensha.taohua
- **写作结构**:三行并列,每行:神煞名:有/无——解读
- **字数上限**:220 字
- **语气**:中性偏故事感
- **禁止**:自行计算锚点之外的神煞;把桃花直接推断为外遇或婚姻状态
- **依赖字段**:无
- **机器校验**:常规(禁词/字数/干支存在性)

### 性格与行为模式

- **职责**:十神结构驱动的性格画像
- **输入数据**:anchors.tenGods、anchors.strength、facts.wuXing
- **触发条件**:主导十神+次强十神+旺衰档+最强五行共同决定画像;不同命盘必须产出不同人物标签
- **命理推导规则**:
  - 按主导/次强十神写外在表现→内在动机→内外反差→心理底色
  - 结合旺衰档写能量水平(身强的推进感/身弱的借力感)
  - 收束一句有辨识度的人物判断
- **必引证据**:tenGod.1 / tenGod.2 / structure.strength
- **写作结构**:外在表现 → 内在动机 → 内外反差 → 心理底色 → 收束句(自然段)
- **字数上限**:370 字
- **语气**:人物特稿
- **禁止**:MBTI式贴标签;万金油描述(外冷内热之类无依据定性)
- **依赖字段**:旺衰定性
- **机器校验**:常规(禁词/字数/干支存在性)

## 02 格局(3 字段)

### 月令格局

- **职责**:月令取格的定名与人生路径含义
- **输入数据**:anchors.pattern、facts.transparentStems、anchors.monthOrder
- **触发条件**:格局名/成色/从格标记由引擎确定性判定;月令逢冲时须提及根基受动
- **命理推导规则**:
  - 先写盘面事实:引用格局判定的 basis(月令藏干透出/建禄/阳刃/从格取势)
  - 格局名打「」(连同格字),必须与锚点一致
  - 成色按 tier 表述(本气透出层级高/余气透出偏弱/藏而不透以本气论)
  - 落到人生路径含义与聚焦建议,不空谈格局定义
- **必引证据**:structure.pattern
- **写作结构**:盘面事实 → 格局名(「」) → 路径含义 → 聚焦建议(条件句收尾)
- **字数上限**:240 字
- **语气**:专业断语
- **禁止**:给出锚点之外的格局名;强套格局;把格局直接等同富贵层次
- **依赖字段**:旺衰定性
- **机器校验**:必须含「」结论词;必须引用具体干支

### 命盘结构特征

- **职责**:2-3 个最显著干支组合的结构解读
- **输入数据**:facts.relationTexts、anchors.tenGods、facts.transparentStems
- **触发条件**:从关系清单(合冲刑害/三合)与透干十神中提炼最显著的 2-3 个组合;关系少时以透干结构为主
- **命理推导规则**:
  - 每个组合独立成段:结构名(核心优势/双刃剑)→ 具体干支依据 → 现实解读 → 定性收尾
  - 结构名必须与实际盘面相符(如伤官生财/杀印相生/食神制杀/财官双美)
  - 天干五合与六合只论合不默认化(锚点声明)
  - 三合局须引用化神五行
- **必引证据**:relation / tenGod
- **写作结构**:组合1(结构名+依据+解读+收尾)→ 组合2 → 组合3
- **字数上限**:530 字
- **语气**:结构解析
- **禁止**:引用判断对象里不存在的关系;断化气;把双刃剑只写成优势
- **依赖字段**:月令格局
- **机器校验**:必须引用具体干支

### 结构清浊

- **职责**:命局清浊与发力主线
- **输入数据**:facts.relationTexts、anchors.pattern、anchors.tenGods
- **触发条件**:关系少而顺=清(发力主线明确);刑冲多=浊(内耗与拉扯);按实际关系清单定性,不由字数凑
- **命理推导规则**:
  - 一段话直接说清浊与发力主线
  - 用「用X生X」或「以X制X」点出主线
  - 以条件句收尾(只要大运流年不来破坏…)
- **必引证据**:relation
- **写作结构**:清浊定性 → 主线(「用X生X」) → 条件句收尾
- **字数上限**:190 字
- **语气**:凝练断语
- **禁止**:与命盘结构特征重复论述同一组合
- **依赖字段**:命盘结构特征
- **机器校验**:必须含「」结论词
